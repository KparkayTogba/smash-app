# Smash — Website

Public website for the **Smash** dating app. Built as static HTML — no build step required.

## About

Smash is a personality-first social dating app designed to help people build authentic connections — through guided prompts, expressive profiles, and intentional discovery.

Unlike traditional dating apps, Smash goes beyond photos. Users answer personality prompts that reveal who they really are, enabling deeper matches based on values, humor, and relationship goals. Authentication is fully passwordless — sign in with just your email and a one-time code.

**Key features:**
- Personality prompts for deeper self-expression
- Intentional discovery based on interests and goals
- Real-time messaging between matched users
- Passwordless OTP login — no password ever stored
- Full privacy control — delete your account instantly
- Safety-first community with 24hr report response
